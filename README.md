# きょうも、一歩。 — 学習特訓

歴史・公民・北辰英語・英単語の学習を「武南高校までの道のり」につなげる静的アプリです。

## 道のりの調整

`journey-config.js` の `JOURNEY_CONFIG` で総距離、1ポイントの距離、正解ポイント、苦手克服ボーナス、単語習得ポイント、チェックポイントを変更できます。初期値は8km、初回正解10ポイント、苦手克服20ポイント、単語習得10ポイント、1ポイント=1mです。

各問題の正解・苦手克服、各レベルの単語習得は、それぞれ一度だけ加算します。問題の追加や単語の学習への戻し、教科記録のリセットで重複加算しません。新しい科目でも安定した固有IDで `window.studyJourney.answer(id, correct, wasWeak)` を呼び出せます。単語習得は `window.studyJourney.master(id)` です。

獲得時の距離と最高到達距離を保存するため、設定変更・問題追加によって過去の距離は減りません。設定変更は以後の獲得分に適用します。総距離を延長した場合は残り距離が増えますが、現在地点は変わりません。ゴール後も距離を蓄積します。週は端末の現地時間の月曜日始まりです。

## 保存と互換性

従来の `historyQuiz` / `civicsQuiz` / `englishQuiz` / `history-study-app.target1800.v1` は変更しません。道のりは独立した `history-study-app.journey.v1` に保存します。導入前の解答を距離へ遡及換算せず、更新後の学習から加算します。端末やブラウザ間の自動同期はありません。ブラウザのサイトデータを消去すると進捗も消去されます。

既存の問題・単語データ、4択、記述、空欄、語順、解説、ふりかえる、発音、苦手復習、習得済みの解除を維持しています。英単語はレベル2 p.164–257、レベル3 p.260–323、レベル4 p.326–381。既存の出典・保留項目は画面内に残しています。

## 公開

`index.html`、`journey.css`、`journey-config.js`、`journey.js` を同じ階層に配置。GitHub Pages は main / root から公開します。ビルドや外部サービスは不要です。

## 確認

既存データの一致、JavaScript構文、正解・苦手克服・習得加算、重複防止、再読み込み、設定変更後の距離維持、破損した道のり保存データの保護を検証しました。実ブラウザでも歴史クイズの正解、英単語習得、保存復元を確認。音声の実機再生はiPhoneでの確認が必要です。
